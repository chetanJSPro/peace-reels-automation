# Assets folder

Put only legitimate files here:

- `assets/videos/` — your own footage or downloaded free stock videos that allow commercial YouTube use.
- `assets/music/background.mp3` — a background track from Pixabay Music, Mixkit, YouTube Audio Library, or your own music.

Recommended practice:

1. Keep the original source URL in the generated metadata file.
2. Do not use footage containing logos/brands as if they endorse you.
3. Do not mislabel generic footage as a specific place. If unsure, use a generic top label like `GANGA GHAT | INDIA` or `NATURE | INNER PEACE`.
4. Avoid using clips of identifiable people in a negative/offensive spiritual or health context.
